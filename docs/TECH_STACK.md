# Technology Stack

The project utilizes a state-of-the-art stack for deep learning and web deployment.

## ⚙ Core Frameworks
- **Python 3.10+**: Core programming language.
- **PyTorch**: Deep learning framework for model implementation and training.
- **Hugging Face Transformers**: For implementing the BERT (Bidirectional Encoder Representations from Transformers) model.

## 📊 Data & Processing
- **Pandas**: Efficient data manipulation and CSV handling.
- **NumPy**: Numerical operations and tensor transformations.
- **NLTK (Natural Language Toolkit)**: Proactive text cleaning (stopword removal and preprocessing).

## 🛡 Metrics & Performance
- **Scikit-learn**:
  - `StratifiedShuffleSplit` for robust data division.
  - `compute_class_weight` to handle data imbalance.
  - `accuracy_score` and `f1_score` for model validation.

## 🎨 User Interface (Frontend)
- **Streamlit**: High-performance library for building interactive data apps.
- **Custom CSS & HTML**: Used for 'Glassmorphism' UI design and premium styling of the dashboard.
