# Psychological Distress Detection (Research Prototype)

A research prototype for classifying social media text with a BERT + CNN + attention model and a Streamlit interface. It is for learning and demonstration only. It is **not** a clinical assessment, diagnostic tool, or crisis service.

## What works from this repository

The repository includes the training and inference code, documentation, requirements, and two small CSV datasets plus five JSON annotation files. It does not include the local Python virtual environment, the trained model checkpoint, or `Suicide_Detection.csv` (about 167 MB).

Without a checkpoint, the app can be launched after dependencies and model files are downloaded, but its predictions are from randomly initialized classifier weights and are not meaningful. To use trained inference, supply a compatible `best_model.pth` generated by training or obtained separately. The optional `Suicide_Detection.csv` is not required: training can use the smaller checked-in CSVs.

## Quick start

Use Python 3.10 or newer. From the repository root:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m nltk.downloader stopwords
```

PyTorch installation varies by operating system and accelerator. If the command above does not install a suitable build, install the appropriate PyTorch build using the [official selector](https://pytorch.org/get-started/locally/).

### Train

```bash
python src/train.py
```

Training loads supported CSVs from `data/`, samples up to 4,000 rows, creates one stratified 80/20 train/validation split, and saves the best validation checkpoint as `best_model.pth` in the repository root. This is a single holdout split, not 5-fold cross-validation. The first run also downloads `bert-base-uncased` from Hugging Face. Training time and memory needs depend on the machine; GPU is recommended.

To use an external data folder, set `EXTERNAL_DATASET_DIR` to a folder containing supported CSV files. Or pass a dataset path through the loader from Python. The main optional dataset excluded from this repository is `data/Suicide_Detection.csv`.

### Run the app

```bash
streamlit run src/app.py
```

Open the local URL printed by Streamlit. For useful predictions, first train the model or place a compatible `best_model.pth` in the repository root. The app also needs at least one supported CSV in `data/` to show its dataset summary.

### Evaluate

```bash
python src/evaluate.py
```

Evaluation requires both a checkpoint and a dataset. The script evaluates a holdout split from the data currently loaded; it is not an independent test set if that same data was used for training. Treat its output accordingly.

## Data formats

The loader supports CSVs with text columns such as `text`, `Tweet`, or `content` and labels such as `label`, `class`, `Suicide`, or `severity`. For `status` data it maps broad mental-health labels into a binary target; these labels should not be interpreted as a clinical ground truth. The checked-in `human_n_llm_labeled_rSuicidewatch_posts.csv` uses `content` and `severity` and can be loaded by the project loader.

The data files are provided for project demonstration. Review each dataset's source, license, terms, privacy implications, and citation requirements before redistribution or reuse. Avoid publishing identifiable or sensitive personal text without a valid basis.

## Project structure

```text

docs/                 Architecture, algorithm, implementation, and stack notes
src/data_loader.py    Text normalization and dataset loading
src/model.py          BERT + CNN + attention model
src/train.py          Training with a stratified validation split
src/evaluate.py       Holdout evaluation and confusion matrix
src/app.py            Streamlit interface
requirements.txt      Python dependencies
```
